# Data model

Generated by `scripts/describe_schema.py` from the live DuckDB schema. All values are Open-Meteo model output (past days are model output too), not station observations.

## raw_weather_hourly

Append-only city/hour records from Open-Meteo. Hours already loaded are refreshed in place when the model revises them. Hours are city-local.

| Column | Type | Description |
| --- | --- | --- |
| city | VARCHAR | City name from config.CITIES. |
| hour | TIMESTAMP | City-local hour (no timezone offset stored). |
| ingested_at | TIMESTAMP | When the row was last written or refreshed. |
| temperature_2m | DOUBLE | Air temperature at 2 m, degrees C (raw). |
| precipitation | DOUBLE | Precipitation, mm (raw, model output). |
| wind_speed_10m | DOUBLE | Wind speed at 10 m, km/h (raw). |

## stg_hourly

View over raw: typed, deduplicated, with unit-suffixed column names.

| Column | Type | Description |
| --- | --- | --- |
| city | VARCHAR | City name from config.CITIES. |
| hour | TIMESTAMP | City-local hour (no timezone offset stored). |
| temperature_c | DOUBLE | Air temperature, degrees C. |
| precipitation_mm | DOUBLE | Precipitation, mm. |
| wind_kmh | DOUBLE | Wind speed, km/h. |

## mart_daily_city

One row per city and city-local day. The current day includes forecast hours.

| Column | Type | Description |
| --- | --- | --- |
| city | VARCHAR | City name from config.CITIES. |
| day | DATE | City-local calendar date. |
| avg_temp_c | DOUBLE | Mean of hourly temperature for the day, degrees C. |
| min_temp_c | DOUBLE | Lowest hourly temperature, degrees C. |
| max_temp_c | DOUBLE | Highest hourly temperature, degrees C. |
| total_precip_mm | DOUBLE | Sum of hourly precipitation, mm. |
| max_wind_kmh | DOUBLE | Highest hourly wind speed, km/h. |
| hours_observed | BIGINT | Hourly records in the day (24 when complete; model output, not station observations). |

## mart_exposure_city

Heat/cold hours and degree-hours per city-day (illustrative thresholds, not clinical guidance).

| Column | Type | Description |
| --- | --- | --- |
| city | VARCHAR | City name from config.CITIES. |
| day | DATE | City-local calendar date. |
| heat_hours | BIGINT | Hours at or above the heat threshold. |
| cold_hours | BIGINT | Hours at or below the cold threshold. |
| heat_degree_hours | DOUBLE | Sum of degrees above the heat threshold across hours. |
| cold_degree_hours | DOUBLE | Sum of degrees below the cold threshold across hours. |

## fetch_log

One row per city per fetch: when, how many hours returned, latest hour returned. Drives the source-fetch freshness gate.

| Column | Type | Description |
| --- | --- | --- |
| city | VARCHAR | City name from config.CITIES. |
| fetched_at | TIMESTAMP | When the fetch ran. |
| rows_returned | BIGINT | Hourly rows returned by that fetch (0 means an empty fetch). |
| latest_hour_returned | TIMESTAMP | Latest weather hour in that fetch (usually later than now: forecast horizon). |
